# Записи носителей языка

В приложении разрешены только проверенные записи чеченской речи. Русский TTS
и русский голос для чеченского текста запрещены. Если записи нет, интерфейс
показывает нейтральное состояние «Аудио пока недоступно».

## Подготовка записи

- 44.1 kHz, mono, без музыки и фонового шума.
- Обычная и медленная версии оформляются отдельными клипами.
- Каждый диктор должен иметь запись в `speakers` и ссылку на согласие
  (`consentRef`).
- Для каждого клипа обязательны `speakerId`, `dialect`, `durationMs`,
  `version`, `sha256`, `languageTag`, `license` и `packId`.
- `languageTag` может быть только `ce` или `ce-RU`.

Базовые записи располагаются внутри `assets/audio/` и используют `assetPath`.
Дополнительные офлайн-пакеты объявляются в `downloadablePacks`; для них
обязательны URL, размер и SHA-256 всего пакета.

Источник правды: `assets/data/audio_manifest.json`. Перед публикацией клипа
нужно проверить произношение носителем языка, лицензию, согласие диктора и
контрольную сумму файла.
